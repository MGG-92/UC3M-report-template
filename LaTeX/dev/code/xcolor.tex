\subsection{Xcolor -- Colors}

The \texttt{xcolor} package provides color support in \LaTeX. In this
template, it is mainly used by \texttt{listings} to add syntax
highlighting and other colors to source code.

For example, a code style may define different colors for comments,
keywords and strings:

\begin{lstlisting}[style=latex]
\definecolor{codegreen}{RGB}{0,120,0}
\definecolor{codeblue}{RGB}{0,70,180}

\lstdefinestyle{example}{
    keywordstyle=\color{codeblue},
    commentstyle=\color{codegreen}
}
\end{lstlisting}

Normally, these settings do not need to be defined inside the main
document. The code colors and listing styles are configured in
\texttt{Packages/Code/package\_config.tex}.
