\subsection{Siunitx -- Numbers and Units}

The \texttt{siunitx} package provides consistent formatting for
numbers, physical quantities, and units.


\subsubsection{Physical Quantities}

Use \verb|\qty| to write a numerical value together with its unit:

\begin{lstlisting}[style=latex]
\[
v = \qty{25}{\meter\per\second}
\]
\end{lstlisting}

\[
v = \qty{25}{\meter\per\second}
\]

More complex units can be constructed by combining unit commands:

\begin{lstlisting}[style=latex]
\[
a = \qty{9.81}{\meter\per\second\squared}
\]

\[
\rho = \qty{1.225}{\kilogram\per\meter\cubed}
\]
\end{lstlisting}

\[
a = \qty{9.81}{\meter\per\second\squared}
\]

\[
\rho = \qty{1.225}{\kilogram\per\meter\cubed}
\]


\subsubsection{Units Without Values}

The \verb|\unit| command displays a unit without an associated
numerical value:

\begin{lstlisting}[style=latex]
\[
\unit{\meter\per\second}
\qquad
\unit{\newton}
\qquad
\unit{\pascal}
\]
\end{lstlisting}

\[
\unit{\meter\per\second}
\qquad
\unit{\newton}
\qquad
\unit{\pascal}
\]


\subsubsection{Numbers}

The \verb|\num| command provides consistent formatting for
numerical values:

\begin{lstlisting}[style=latex]
\num{12500}

\num{3.2e8}
\end{lstlisting}

\[
\num{12500}
\qquad
\num{3.2e8}
\]


\subsubsection{Angles}

Angles can be written using \verb|\ang|:

\begin{lstlisting}[style=latex]
\[
\alpha = \ang{30}
\qquad
\beta = \ang{45}
\qquad
\gamma = \ang{90}
\]
\end{lstlisting}

\[
\alpha = \ang{30}
\qquad
\beta = \ang{45}
\qquad
\gamma = \ang{90}
\]
